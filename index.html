Біржі з підключенням по API

Публічні котирування та історичні свічки завантажуються без API-ключів. Приватні API-ключі не вводити у цей HTML-файл. Кількість пар і ліміти плеча демонстраційні, у реальній версії їх треба брати з API біржі. Ключ API створюється без права виведення, а кошти лишаються на біржі.
