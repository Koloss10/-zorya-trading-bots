# Вихідний код Orbix

`orbix.html` — **згенерований** файл. Редагуйте модулі тут, потім зберіть:

```sh
node tools/build.js          # зібрати orbix.html
node tools/build.js --check  # перевірити, що orbix.html актуальний (так робить CI)
node --test tests/engine.test.js
```

Результат — один самодостатній HTML-файл: він працює на GitHub Pages, офлайн і в перегляді файлів на телефоні.

## Структура

| Файл | Що всередині |
|---|---|
| `orbix.template.html` | Розмітка сторінки з мітками `/*@css*/`, `/*@vendor*/`, `/*@app*/` |
| `orbix.css` | Стилі й теми |
| `vendor/lightweight-charts.standalone.production.js` | Бібліотека графіків TradingView Lightweight Charts v5.2.1 (Apache-2.0), вбудовується у файл |
| `js/01-config-pairs.js` | Пари, біржі, генератор демо-даних |
| `js/02-market-data.js` | Реальні дані: свічки спот/ф'ючерси, mark price, funding, правила бірж, кеш |
| `js/03-indicators.js` | Агрегація свічок (UTC), індикатори |
| `js/04-engine.js` | Сигнали входу, торговий рушій (`Bot`), бектест, стрес-тест, Авто-майстер |
| `js/05-walkforward.js` | Walk-forward перевірка |
| `js/06-quality.js` | Якість стратегії: витрати, ринкові режими, стабільність по вікнах, walk-forward конфігурації |
| `js/10-ui-helpers.js` | Форматування, допоміжні функції інтерфейсу |
| `js/11-theme-notify.js` | Теми, звук, сповіщення, Telegram |
| `js/12-charts.js` | Біржовий графік і міні-графіки |
| `js/13-paper-bots.js` | Paper-боти: відтворення з моменту запуску, живе оновлення |
| `js/14-builder-backtests.js` | Конструктор бота, бектест, історія бектестів |
| `js/15-automaster-top.js` | Авто-майстер, Топ Боти, Обрані |
| `js/16-market-journal-stats.js` | Ринок, журнал угод, стрес-тест, статистика |
| `js/17-settings-profile-menu.js` | Налаштування, профіль, аватар, месенджери, довідка, меню |
| `js/18-cloud-auth-security.js` | Хмара Supabase, вхід, 2FA, пароль, блокування пристрою |
| `js/19-testnet.js` | Тестнет Binance Futures: ключі на сервері, пробні ордери, дублювання угод бота |
| `js/20-boot.js` | Запуск застосунку |

Модулі склеюються в один скрипт у порядку назв, тож пізніші можуть використовувати функції попередніх. Модулі `01`–`06` не залежать від інтерфейсу: саме їх завантажують тести рушія.

Серверна частина — у `supabase/`: міграції бази та Edge Functions `tg-notify` (Telegram) і `exchange` (тестнет біржі).
